# v1.151 / Plan 核心工具始终可用语义

## 版本号与版本依据

- 版本：`v1.151`
- 基线：`origin/main` 的 `v1.150: SciFi status pill fallback`，commit `a9ed228f17e43f7c9cc66d9a62ae5a0976ee5780`。
- 版本依据：本轮是 v1 体验优化阶段中对 Plan 权益规则语义的小步修正。它不引入付费能力，只让界面准确描述当前 build 的真实可用性边界。
- 建议提交主题：`v1.151: Clarify always-available tools`

## 背景

`RootContentView.swift` 的 `PlanEntitlementRuleStatus` 当前使用 `case protected`，并显示 `Protected` 与 `lock.open`。`Core local tools` 的 detail 只说明 Generate、Models、Gallery 和 Prompts “stay available”。这些表达容易让用户误以为应用已经存在 entitlement protection 或购买门禁。

当前实现实际上没有 StoreKit 商品请求、购买或恢复流程、receipt validation、subscription、entitlement persistence 或 paid gate。Generate、Models、Gallery 和 Prompts 在本 build 中始终可用，不受购买状态控制。因此，本轮应把状态命名和用户可见/辅助功能文案改为准确的 “Always available / not gated by purchases in this build”。

## 目标

1. 将 `PlanEntitlementRuleStatus.case protected` 重命名为 `case alwaysAvailable`。
2. 将该状态的 title 改为 `Always available`。
3. 将该状态的 `systemImage` 改为 `checkmark.circle`。
4. 保持该状态颜色为 `SciFiTheme.mint`。
5. 将 `Core local tools` entitlement rule item 的 status 改为 `.alwaysAvailable`。
6. 将该 item 的 detail 精确改为：`Generate, Models, Gallery, and Prompts are always available and are not gated by purchases in this build.`
7. 将该 item 的 accessibility hint 精确改为：`Confirms Generate, Models, Gallery, and Prompts are always available and are not gated by purchases in this build.`
8. 保留该 item 自身的 `systemImage: "lock.open"`、row order、其他 entitlement rows、Plan 布局、视觉结构和全部业务逻辑不变。

## 非目标

- 不启用或接入 StoreKit。
- 不添加 product IDs、商品加载、价格、购买按钮、purchase sheet、restore、receipt validation、subscription 或交易处理。
- 不实现 entitlement mapping、entitlement persistence、本地 entitlement cache、跨启动/跨设备恢复、服务端 entitlement source 或任何模拟购买状态。
- 不给 Generate、Models、Gallery 或 Prompts 增加 paid gate；不改变任何生成、模型、图库或提示词业务逻辑。
- 不改变 paid candidates、其他 entitlement rows、availability rows、Mac readiness rows 或其顺序。
- 不启用 Mac Catalyst，不修改 Xcode platform、signing、sandbox 或 notarization 配置。
- 不修改 native backend、bridge、XCFramework、SwiftData schema、文件存储、CI workflow 或测试规范。
- 不做无关重构，不新增抽象，不修改共享 status row 组件。

## 当前架构依据

- UI 层位于 `LocalDiffusion/Views/**`；本轮只修正 `RootContentView.swift` 中 Plan 静态展示模型与文案。
- 当前 Plan 页面是规划和状态说明界面，不请求 StoreKit 商品，也不执行购买、恢复、receipt 或 entitlement 解析。
- `GenerationViewModel` 的生成门禁只检查模型选择与本地文件完整性；Generate、Models、Gallery 和 Prompts 没有购买 gate，本轮必须保持这一事实。
- SwiftData 模型不包含购买或 entitlement schema；本轮不得新增或修改数据模型。
- 推理仍通过 `ImageGenerationBackend` 隔离，UI 不得接触 C/Objective-C++ bridge；本轮不触碰推理边界。
- 状态必须同时通过 title、SF Symbol 和颜色表达，不能只依赖 mint 颜色；`Always available` + `checkmark.circle` 满足该语义与 accessibility 要求。

## 风险

- `Always available` 比 `Protected` 更长，可能增加 status pill 的纵向回退概率；现有共享 `SciFiStatusPill` 已提供窄宽和 accessibility Dynamic Type 回退，本轮不调整布局。
- `lock.open` 作为 row icon 保留以维持现有视觉识别，而 status token 改用 `checkmark.circle` 表达可用性；两者角色不同，需要通过现有组合 accessibility 语义避免误读。
- 本轮不做 Simulator、VoiceOver、iPad Split View、Mac window 或实机截图目检；云端 build 不能替代这些后续视觉验证。
