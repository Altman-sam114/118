# v1.162 iPad 视频模型 UI 可用性

## 版本号

v1.162

## 版本分配依据

v1.161 已完成独立 VideoModel、.ldvideo 本地导入/校验/专用存储和 Models 的 Video Models 分区。本轮是 v1.161 之后的新 UI/QA 轮次，针对 Agent C 明确留下的真实 iPad、Dynamic Type、VoiceOver 和 Reduce Motion 风险递增为 v1.162。

## 背景

RootContentView 在 iPad regular width 使用 NavigationSplitView，在 compact width 使用 TabView；两者都进入 ModelLibraryView。ModelLibraryView 把图片模型、未跟踪 GGUF 文件和 VideoModelsSection 放在同一个 List 中，VideoModelRow 使用 ViewThatFits 处理 header、状态和操作区。

本轮只审计并修复已存在的本地视频模型管理及其 Models UI 可用性。必须先依据实际代码定位具体布局、状态或可访问性问题。静态检查不能声称完成真实 iPad、VoiceOver、Dynamic Type 或 Reduce Motion 设备交互。

## 目标

- 修复已证明的 regular detail、compact width、窄宽度或 accessibility Dynamic Type 下的 Models/Video Models UI 问题，保证文字不重叠、不裁切，操作区稳定可用。
- 保留当前暗色科幻设计、8px 内圆角、既有信息层级、稳定尺寸和至少 44pt 交互区。
- 让 deploymentStatus 和 inferenceAvailability 在视觉及 VoiceOver 中明确区分；Deployed/Ready 不得被误解为可生成视频。
- 使导入、重新检查、删除确认、错误 alert、loading feedback 的 label/value/hint 与实际 action、状态一致。
- 检查 Reduce Motion；如没有真实动效问题，记录“不改”的审计结论，不为制造 diff 引入动画。

## 非目标

- 不实现视频生成 backend、VideoInferenceBackend 实际推理、帧序列、编码、播放器、Gallery 视频实体或图片/视频混淆。
- 不修改 ImageGenerationBackend、GenerationViewModel、图片 LocalModel 下载/删除/选择流程，不让 VideoModel 进入 Generate。
- 不修改 StoreKit、购买/恢复、receipt、subscription、entitlement persistence、付费解锁或 Mac Catalyst；不声称虚假 Mac 支持。
- 不扩大到 Gallery、Prompt、Plan 或共享组件全局改版；除非证明为 Models UI 必需，不改 ParameterEditor、native bridge、XCFramework、workflow 或 Xcode project。
- 不修改 SwiftData schema、文件存储、VideoModelPackageService 校验契约或视频导入/删除业务逻辑。
- 不做大范围导航重构、不引入真实视频下载、不下载大模型/大 artifact。
- 不把本机 parse、CI build 或截图冒充真实设备体验验证。

## 当前架构

- UI 层为 LocalDiffusion/Views/**，只负责展示、输入、导航和用户反馈；不得直接调用 native C/Objective-C++ bridge。
- RootContentView 由 horizontalSizeClass 选择 NavigationSplitView 或 TabView；Models detail 都是 ModelLibraryView。
- ModelLibraryView 通过 SwiftData @Query 读取 LocalModel/VideoModel，负责导入触发、刷新、删除确认、错误 alert 和 loading overlay。
- VideoModelsSection 只接收 models、isImporting、onImport、onCheck、onDelete closures。
- VideoModel 的 deploymentStatus 与 inferenceAvailability 是独立状态；当前本地导入成功后可为 deployed/ready，但 inference unavailable。
- 视觉基线是暗色科幻主题、SciFiStatusPill/button styles、8px panel 圆角和至少 44pt 命中区。优先 Label、SF Symbol、accessibilityLabel/value/hint、ViewThatFits 和可伸缩 stack；禁止 UIScreen.main.bounds、固定宽度和只凭颜色表达状态。
- 必须遵守 SwiftUI Pro 的 views/data/navigation/design/accessibility/performance/swift/hygiene 参考：Dynamic Type、VoiceOver、Reduce Motion、Button 语义、可取消异步任务、避免不必要固定 frame 和重复计算。

## 验收边界

### iPad regular width

NavigationSplitView 的 Models detail 中 sidebar 不遮挡 detail；List section、Storage Matrix、Video Models header/footer、video row header/status/actions 可滚动查看。长模型名、source/version、package type、size 和 Inference unavailable 必须换行或可靠纵向回退，不重叠、不裁切、不把按钮推出可用区域。

### compact width

同一 Models UI 在 TabView/窄宽度下保持单列滚动；视频空态、导入入口、footer、状态和操作不依赖 regular 宽度。compact 修复不得破坏 regular 布局。

### Dynamic Type

普通字号维持现有密度和顺序；accessibility Dynamic Type 下标题、状态、错误、空态 footer、按钮文本完整可读，控制区可靠回退为纵向或可伸缩布局。不使用固定字号、固定高度或截断关键文案。

### VoiceOver

section 标题、模型名、source/version、package type、size、deployment status、inference availability、last error（若展示）顺序合理且不重复。Import/Check/Remove/Cancel/Refresh/Menu 的 label/value/hint 与实际 action 一致；装饰图标不生成无意义节点；确认 dialog 说明实际目录和不影响图片模型。Ready/Deployed 不得朗读成可生成视频。

### Reduce Motion

Models 相关 loading/状态变化没有本轮引入的大幅或持续动画；必要反馈使用静态或 opacity 友好方式。未实际执行设备检查的部分必须明确标注未验证。

### 设备验证边界

本轮默认不运行完整本机 build/simulator，也没有真实 iPad、Dynamic Type、VoiceOver 或 Reduce Motion 设备交互权限时，必须如实列为未验证；CI build 只能验证工程可构建，不能替代体验验收。

## 文案、按钮和状态布局

- 保留现有用户可见命令，只有误导时才改；导入、检查、删除 label 必须说明 video package/deployment，避免与图片 GGUF 混淆。
- Ready/Deployed 必须伴随 Inference unavailable 或等价明确能力说明；禁止 “Video ready to generate”等未实现承诺。
- 错误需包含 package/model 对象和实际失败原因；loading value 需说明正在导入 video package，不能只朗读 Busy 或颜色。
- ready 行同时显示部署结果和推理不可用结果；failed/unsupported 行显示可理解的现有 lastError，不显示过时 ready 信息。
- 删除确认只删除视频包和部署记录，明确不影响图片模型；取消后清理 pending 状态并保留现有 action。

## 风险和禁止项

- ViewThatFits 在不同父级宽度和 Dynamic Type 下可能选择不同结构；调整必须同时检查 regular、compact 和 accessibility size，避免按钮被挤出或重复 accessibility 节点。
- List section/footer、overlay、alert 和 NavigationSplitView detail 可能造成滚动/焦点问题；不要用固定屏幕宽度、硬编码高度或负 padding 掩盖约束。
- 过度合并 accessibilityElement(children: .ignore) 可能丢失可操作按钮；过度拆分又会重复朗读，必须以实际语义顺序为准。
- deploymentStatus == .ready 只表示包完整并已部署；不得改成 inference ready，不得添加 mock 视频输出、帧或播放器。
- 禁止直接调用 native bridge，禁止修改图片 backend、Generate、Gallery、Prompt、StoreKit、Mac Catalyst、平台设置、workflow 或无关共享样式。
- 禁止无确认删除/覆盖用户文件，禁止下载大模型或历史 artifact，禁止还原用户/其他 Agent 改动，禁止伪造设备测试、CI、commit、run、artifact 或 Agent C 核对结论。
- 若没有可证明 UI 问题、需要人工设备才能判断的争议、或修复会扩大架构边界，立即缩小为审计报告或停止，不要制造 diff。
