# v1.150 / SciFiStatusPill 窄宽度回退

## 版本号

- 版本：`v1.150`
- 阶段：`v1（体验优化）`

## 版本分配依据

- 当前最新正式版本为 `v1.149 / Gallery 详情参数行窄宽度回退`。
- 人工总目标要求持续优化 Mac/iPad/UI/设计/付费功能。
- v1.147 已为共享 `SciFiMetric` 增加窄宽度回退；共享 `SciFiStatusPill` 仍固定 `Label` 横排 icon/title，在窄 pill / 长标题（如 Backend Offline、长 sampler/model status）下可能压缩。本轮补齐同一模式。

## 背景

`SciFiStatusPill` 当前始终使用 `Label(title, systemImage:)`。accessibility Dynamic Type 仅放开 `lineLimit`，普通字号仍单行。胶囊在窄列或长标题时 icon 与文字可能挤在一起。本轮在普通 Dynamic Type 下用 `ViewThatFits(in: .horizontal)` 优先保留横排 Label，空间不足时回退为纵向 icon + title，不改变颜色、padding、accessibility combine 语义。

## 目标

1. 修改 `SciFiStatusPill.body`。
2. accessibility Dynamic Type 下使用纵向 icon + multi-line title（可换行）。
3. 普通 Dynamic Type 使用 `ViewThatFits`：优先既有横排 `Label`，不足时回退纵向 icon + title。
4. 保留颜色、capsule 背景/描边、padding、font weight、accessibility combine。

## 非目标

- 不修改调用方（Generate console、Models rows、Prompt metric pills 等）业务逻辑。
- 不修改 ParameterEditor 其他控件、native、StoreKit、Mac Catalyst、workflow。
- 禁止本地 Xcode / Simulator / 真机构建测试。

## 当前架构依据

- `SciFiStatusPill` 位于 `LocalDiffusion/Views/Shared/ParameterEditor.swift`，是 Generate、Models 和 Prompts 共用的纯展示组件。
- 本轮只调整 SwiftUI 布局和 Dynamic Type 回退，不改变调用方状态、SwiftData、文件存储、`GenerationViewModel` 或 `ImageGenerationBackend` 边界。
- 横向候选必须以固有宽度参与 `ViewThatFits`，避免单行文本先被压缩或截断而绕过纵向回退。

## 实现步骤

抽出 `horizontalPill`（现有 Label，并固定其横向固有宽度供 `ViewThatFits` 判断）与 `verticalPill`（VStack icon + Text）。

```swift
if dynamicTypeSize.isAccessibilitySize {
    verticalPill
} else {
    ViewThatFits(in: .horizontal) {
        horizontalPill
        verticalPill
    }
}
// shared chrome: padding, capsule, stroke, accessibilityElement(children: .combine)
```

同步 README / flow / flowchart / update_log。
