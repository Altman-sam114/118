## 背景与审计事实

当前 Models 页在 `ModelLibraryView.swift` 中使用以下条件决定全空态：tracked `LocalModel` 为空、untracked GGUF 文件为空、`VideoModel` 为空。也就是说，视频模型已经属于全空态的真实状态判定。

但全空态的可见 message 仍只说“Add a Hugging Face GGUF model”，VoiceOver value 只说没有 tracked model 或 untracked GGUF file，hint 也只提供 Download/Import GGUF 两个下一步。第三个已经存在且可用的 `Import Video Package` 入口没有出现在这组状态摘要中，视频 inference unavailable 事实也没有在全空态被说明。

这不是视频能力缺失可以忽略的文案差异：用户在 compact `TabView`、regular `NavigationSplitView` detail 或 accessibility Dynamic Type 下看到的是同一个 Models 空态，辅助功能用户会得到不完整的模型库存和下一步信息。

当前 `VideoModelsSection.swift` 已经在 Xcode target 中，并且包含 Video Models 的状态、导入、检查、移除和 inference unavailable 语义；但是 `md/test.md` 的固定普通/native Swift parse 源文件列表没有它，`.github/workflows/ci-results.yml` 的 `swift_sources` 也没有它。v1.162 提示词要求覆盖该文件，当前固定 CI 源集未兑现这一要求。

v1.164 的 `VideoGenerationBackend`、`UnavailableVideoGenerationBackend`、`video-native-dependency-manifest.json` 和 preflight 脚本是独立的能力边界。当前 app 不读取 CI preflight JSON 作为运行时 UI 状态，也没有真实 video engine、编码器、播放器或视频输出。

## 本轮目标

1. 修正 Models 全空态的可见说明，使它同时表达图片 GGUF 模型入口、untracked GGUF 文件入口和独立 `.ldvideo` 视频包入口。
2. 修正全空态的 VoiceOver label/value/hint，使其准确说明没有 tracked GGUF、没有 untracked GGUF、没有 deployed video package，并列出三个真实可用的下一步。
3. 在全空态文案中明确：导入视频包只做本地部署/完整性检查，当前 build 的 video inference 仍为 `Inference unavailable`；不得让用户理解为可生成视频。
4. 保持 compact 与 regular 使用同一组状态/文案来源，保留现有三项按钮、导入互斥、按钮 disabled 逻辑和真实 action 不变。
5. 把 `LocalDiffusion/Views/Models/VideoModelsSection.swift` 加入 `md/test.md` 固定的普通 iOS parse 和 `USE_STABLE_DIFFUSION_CPP` native parse 源文件列表，并同步加入 `.github/workflows/ci-results.yml` 的 `swift_sources`，使该已编译 UI 文件受到 CI 语法覆盖。
6. 保持 v1.164 的 dependency-blocked/unavailable 事实、v1.161 的 VideoModel 独立部署边界和图片生成链路完全不变。

## 事实边界

| 事实 | 本轮可表达的含义 | 禁止表达 |
| --- | --- | --- |
| `VideoModel` 已存在 | 本地视频包可独立导入、检查和移除 | 视频模型已可推理 |
| `deploymentStatus == .ready` | 包目录和声明文件通过当前部署检查 | native video engine 已 ready |
| `inferenceAvailability == .unavailable` | 当前 build 不提供视频推理 | 预计马上可生成或已在后台加载 |
| v1.164 preflight | 当前依赖证据不足，gate 保持 blocked/unavailable | 把 `nm` 观察到的符号当作 ABI |
| `Import Video Package` | 打开显式 `.ldvideo` 文件选择器并部署/检查包 | 下载模型或开始生成视频 |
| fixed Swift parse source list | 对已编译 UI 文件增加语法覆盖 | 代替 iPad、VoiceOver 或真实推理验证 |

全空态文案可以复用当前项目已经使用的英文用户界面风格，但必须同时出现或等价表达以下事实：

- 目前没有 tracked GGUF models。
- 目前没有 untracked GGUF files。
- 目前没有 deployed video packages。
- 可以 Download from Hugging Face、Import GGUF File 或 Import Video Package。
- Video package deployment/checking is separate and video inference is unavailable in this build。

不要在全空态说“没有 models”后只指向 GGUF，因为条件实际上也包含视频包；不要说“生成视频”“ready video model”或“video model available”。

## 架构依据

- `RootContentView` 只按 `horizontalSizeClass` 选择 compact `TabView` 或 regular `NavigationSplitView`；两种容器都进入同一个 `ModelLibraryView`，本轮不改 Root。
- `ModelLibraryView` 是 Models UI 的状态编排层，读取 `LocalModel`、`VideoModel` 和 untracked 文件查询，拥有全空态入口、importer、mutex、overlay、alert 和保存 action。
- `VideoModelsSection` 是独立视频部署状态展示层，接收 models 和 closures；它不应该接收图片模型对象，也不应该调用 native。
- `VideoModel` 的部署状态与 inference availability 是两个不同字段；UI 必须继续分别说明。
- `VideoGenerationBackend` 只定义未来视频推理边界；当前唯一实现为 unavailable/dependency-blocked，不能因为本轮做 UI copy 就接入它的 native 路径。
- SwiftData 仍保存元数据，视频包仍由 `VideoModelPackageService`/`AppFileStore` 管理独立 `VideoModels` 目录。
- 本轮的 UI 状态 copy 是展示层事实摘要；不得把 CI preflight 文件路径或脚本输出当作运行时数据源。
- `.github/workflows/ci-results.yml` 的 `swift_sources` 是固定 parse 的单一源列表；新增 `VideoModelsSection.swift` 时普通和 native parse 必须共用同一完整列表。

## 状态与呈现矩阵

| 场景 | 当前条件 | 本轮期望可见/VoiceOver 摘要 | Action 与数据行为 |
| --- | --- | --- | --- |
| 全部为空 | tracked、untracked、video 都为空 | 明确三类都为空；列出 GGUF 下载、GGUF 导入、视频包导入；说明 video inference unavailable | 三个现有入口保留；不改变 disabled/mutex |
| 只有图片模型为空但有 untracked GGUF | `models.isEmpty == true`、untracked 非空 | 不进入全空态；保留现有 Untracked Files section | 不改变 |
| 只有视频包存在 | `videoModels.isEmpty == false` | 不进入全空态；由现有 Video Models section 展示 Deployed/Unsupported/Failed 与 Inference unavailable | 不改变 |
| 视频包导入中 | `isImportingVideoPackage == true` | 全空态或 section 现有 import value/hint 继续说 Importing，不能说 Ready | 不改变 import mutex、overlay 和 action |
| 其他模型导入中 | `isImportingAnyModel == true` | 视频入口现有 unavailable/blocking 语义继续存在 | 不改变互斥 |
| v1.164 dependency gate | 当前没有 supported video contract | 文案只表达 inference unavailable/contract unavailable/依赖未满足，不表达 ready | 不读取 preflight、不调用 native |
| accessibility Dynamic Type | 大字号环境 | 空态 message、value、hint 和按钮文字可换行，不横向重叠、不裁切 | 不用固定屏幕宽度或缩放文字 |
| compact/regular | 同一 Models state | 文案和 VoiceOver 语义一致；只让父容器负责布局 | 不添加第二份状态 |
