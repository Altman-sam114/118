- 版本依据：在 v1.151 的 StorageMatrix/存储摘要体验基础上，修复窄宽度下 `StorageSummaryRow` 两列指标布局无法自然回退的问题。本轮只调整指标布局策略，不改变存储统计、模型状态或业务逻辑。

## 背景与现状问题

`ModelLibraryView.swift` 中的 `StorageSummaryRow` 当前使用固定的两列 `Grid` 展示存储指标。普通 Dynamic Type 环境下，窄屏、分屏或可用宽度受限时，两列内容仍被约束在横向 Grid 中，较长标题或格式化后的值可能出现拥挤、截断或不可读布局。

当前问题集中在指标展示容器，而不是数据来源、格式化器、面板结构、标题、ready pill 或模型逻辑。修复应让普通 Dynamic Type 优先保留现有两列视觉密度，并在实际宽度不足时自动切换到纵向堆叠；辅助功能字号则直接采用堆叠布局，避免依赖横向试排。

## 目标

1. 为 `StorageSummaryRow` 的指标区域增加窄宽度自适应回退。
2. 普通 Dynamic Type 使用 `ViewThatFits(in: .horizontal)`：
   - 首选项必须是当前两列 `Grid`。
   - 首选 Grid 必须设置 `.fixedSize(horizontal: true, vertical: false)`，使 `ViewThatFits` 能按 Grid 的真实横向需求判断是否容纳。
   - 当横向空间不足时，回退到纵向 stacked 指标布局。
3. accessibility Dynamic Type 不参与横向 Grid 试排，直接使用 stacked 指标布局。
4. stacked 布局中的每个指标按 title/value 纵向排列；value 必须允许垂直方向换行，不能因单行假设而截断。
5. 保持现有指标顺序、显示文本、颜色、格式化器、面板外观、accessibility 语义、header、ready pill 和模型逻辑不变。
6. 同步 README、核心流程、流程图和更新日志，使文档准确描述当前响应式行为和验证基线。

## 实现要求

### 1. Dynamic Type 分流

在 `StorageSummaryRow` 获取当前 Dynamic Type size，并明确区分普通字号与 accessibility 字号：

- accessibility size：直接渲染 stacked 指标布局。
- ordinary size：渲染 `ViewThatFits(in: .horizontal)`，按声明顺序尝试两列 Grid 和 stacked fallback。
- 不得通过硬编码屏幕宽度、设备型号或 GeometryReader 阈值判断布局。

### 2. 普通字号的 ViewThatFits

普通 Dynamic Type 下的结构必须满足：

```swift
ViewThatFits(in: .horizontal) {
    currentTwoColumnGrid
        .fixedSize(horizontal: true, vertical: false)

    stackedMetrics
}
```

要求：

- 第一个候选保留当前两列 Grid 的指标顺序、间距、对齐和视觉表达。
- `.fixedSize(horizontal: true, vertical: false)` 必须应用到作为首选候选的 Grid，使它报告完整横向理想尺寸，同时保留垂直内容适应能力。
- 第二个候选是完整 stacked fallback，不能只是压缩后的两列 Grid。
- 不得用 `AnyView`、手工宽度猜测或状态驱动测量替代 `ViewThatFits`。

### 3. Accessibility 直接堆叠

- 当 Dynamic Type size 属于 accessibility 范围时，直接使用 stacked 布局。
- accessibility 路径不得先构造或依赖横向 Grid 是否 fit 的结果。
- 保持原有 accessibility label/value、元素组合方式、读取顺序及其他语义；仅改变视觉布局所需的容器结构。

### 4. Stacked 指标布局

- 指标顺序必须与当前两列 Grid 的逻辑读取顺序一致。
- 每个指标内部采用 title 在上、value 在下的纵向结构。
- title 和 value 的现有文案、字体角色、前景色和 formatter 输出不得改变。
- value 必须支持垂直换行，至少不得使用会强制单行或垂直截断的设置；需要时使用与现有风格兼容的 multiline alignment、垂直 fixed size 或 layout priority。
- stacked 指标之间保持清晰且一致的垂直间距，不新增卡片嵌套或装饰。

### 5. 必须保持不变的行为

逐项核对以下内容没有语义或视觉回归：

- 指标展示顺序。
- 所有标题和值的显示文本。
- 指标标题和值的颜色。
- byte/count/状态等现有格式化器及其输出。
- StorageSummaryRow 所在 panel 的背景、边框、圆角、内边距与层级。
- accessibility label、value、hint、identifier、sort priority 或 children 行为。
- header 的内容、布局职责和样式。
- ready pill 的文案、颜色、条件和位置逻辑。
- 模型筛选、状态判断、下载、导入、删除、存储统计和其他业务逻辑。
